## فارسی

این نسخه برای تلویزیون SAM R4 با فریمور آزمایش‌شده آماده شده است. در برنامهٔ نصب، گزینهٔ **«شناسایی بدون تغییر»** اضافه شده تا دارندگان مدل‌های دیگر هم بتوانند مشخصات اصلی دستگاه را ببینند. این بررسی هیچ برنامه‌ای نصب نمی‌کند و تنظیمات تلویزیون را عوض نمی‌کند.

گزینهٔ جداگانهٔ **«آزمون و نصب آزمایشی»** هم اضافه شده است. برای آن باید هشدار را بخوانید و `EXPERIMENT` را وارد کنید. برنامه پیش از تغییر نسخهٔ پشتیبان می‌گیرد، بخش‌های اصلی را فعال می‌کند و منتظر آزمایش Home و HDMI با کنترل واقعی می‌ماند. `PASS` نصب را کامل می‌کند؛ هر پاسخ دیگر، بازیابی را شروع می‌کند. این مسیر روی مدل‌های دیگر هنوز آزمایش میدانی نشده و اگر تلویزیون روشن نشود یا ADB قطع شود، بازگشت خودکار ممکن نیست.

پیش از نصب، هشدار مربوط به نسخهٔ پشتیبان و شرایط بازیابی نمایش داده می‌شود. راهنمای نصب فارسی و انگلیسی هم به‌روز شده‌اند.

برای شروع فقط فایل مناسب رایانه‌تان را بگیرید: `SAM-TV-v0.1.5-windows.zip` یا `SAM-TV-v0.1.5-linux.tar.gz`.

## English

This release adds **Read-only discovery** and a separate **Experimental trial** for other Android 11 Realtek TVs. The trial requires an explicit warning acknowledgment, verifies a recovery backup, then lets the user test Home and HDMI with the physical remote. `PASS` continues installation; any other response attempts restore. The experimental path has not been field-tested on another model, and automatic restore cannot run if the TV stops booting or ADB becomes unreachable.

The installer now shows a recovery warning before installation. The Persian and English guides have been updated. Download only the Windows ZIP or Linux TAR.GZ for your computer.
