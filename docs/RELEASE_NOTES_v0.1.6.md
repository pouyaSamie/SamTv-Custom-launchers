## فارسی

کار با برنامهٔ نصب ساده‌تر شد. برای انتخاب‌ها فقط **`y`، `n` یا Enter** لازم است. تنها چیزی که باید به‌صورت متن وارد کنید، **آدرس IP تلویزیون** است.

در نصب معمولی، چهار گزینهٔ پیشنهادی با Enter انتخاب می‌شوند و پیش از شروع نصب، برنامه تأیید `y` می‌خواهد. در آزمون آزمایشی هم هشدار با یک پرسش بله/خیر تأیید می‌شود. پس از امتحان‌کردن Home و HDMI، `y` نصب را ادامه می‌دهد؛ `n` یا Enter بازیابی را شروع می‌کند.

شرایط سازگاری و نسخهٔ برنامه‌های تلویزیون نسبت به 0.1.5 تغییر نکرده‌اند. این مسیر روی مدل‌های دیگر هنوز آزمایش میدانی نشده است. بازگشت خودکار همچنان به روشن‌شدن تلویزیون و دسترسی ADB نیاز دارد.

برای شروع فقط فایل مناسب رایانه‌تان را بگیرید: `SAM-TV-v0.1.6-windows.zip` یا `SAM-TV-v0.1.6-linux.tar.gz`.

## English

The setup wizard now uses only **`y`, `n`, or Enter** for choices. The **TV IP address** is the only free-text input.

Normal installation asks for a final `y` before changing the TV. The experimental warning is also a yes/no question. After testing Home and HDMI, `y` continues installation; `n` or Enter starts restore.

Device compatibility checks and TV APKs are unchanged from 0.1.5. The experimental path has not been field-tested on another model. Automatic restore still requires a booting TV and working ADB.
