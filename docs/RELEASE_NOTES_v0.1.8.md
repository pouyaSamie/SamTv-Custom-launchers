## فارسی

متن داخل برنامهٔ نصب در نسخهٔ 0.1.8 انگلیسی است. نمایش راست‌به‌چپ فارسی در پنجرهٔ فرمان ویندوز روی رایانه‌های مختلف قابل اطمینان نبود؛ راهنمای فارسی همچنان تمام مراحل و معنی پرسش‌های برنامه را توضیح می‌دهد.

برای شروع، فقط [فایل ویندوز](https://github.com/pouyaSamie/SamTv-Custom-launchers/releases/download/v0.1.8/SAM-TV-v0.1.8-windows.zip) یا [فایل لینوکس](https://github.com/pouyaSamie/SamTv-Custom-launchers/releases/download/v0.1.8/SAM-TV-v0.1.8-linux.tar.gz) را متناسب با رایانه‌تان بگیرید و [راهنمای نصب فارسی](https://github.com/pouyaSamie/SamTv-Custom-launchers/blob/v0.1.8/docs/INSTALL.fa.md) را دنبال کنید. در پرسش‌های برنامه، `y` یا Enter یعنی تأیید و `n` یا Esc یعنی رد کردن.

شرایط سازگاری و فایل‌های تلویزیون نسبت به نسخهٔ 0.1.7 تغییر نکرده‌اند.

## English

Version 0.1.8 uses English for all installer console prompts on Windows and Linux. Persian text in Windows Command Prompt could not be verified to display correctly across computers, so the [Persian installation guide](https://github.com/pouyaSamie/SamTv-Custom-launchers/blob/v0.1.8/docs/INSTALL.fa.md) now explains the English prompts step by step.

Download only the [Windows installer](https://github.com/pouyaSamie/SamTv-Custom-launchers/releases/download/v0.1.8/SAM-TV-v0.1.8-windows.zip) or [Linux installer](https://github.com/pouyaSamie/SamTv-Custom-launchers/releases/download/v0.1.8/SAM-TV-v0.1.8-linux.tar.gz). `y` or Enter accepts each yes/no prompt; `n` or Esc declines it.

Compatibility checks and TV APKs are unchanged from 0.1.7.
